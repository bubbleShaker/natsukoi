# ナツコイ — 仮想世界の花札決戦

乗っ取りAI〈ノイズ〉と、アカウントを賭けて花札こいこいで勝負するスマホ向けブラウザゲーム。

**遊ぶ：https://bubbleshaker.github.io/natsukoi/**

- 花札を知らなくても大丈夫：タイトルの「れんしゅう」で 1 手ずつ案内、「あそびかた・役」で札と役の一覧、対局中は「ヒント」ボタンと「？」
- 3 / 6 / 12 か月勝負。役ができたら「こいこい」か「勝負」
- 大きく負け越すと、世界中のアバターがアカウントを託してくれる（次の勝ちが 2 倍）
- ビルドなしの ES Modules。札の絵・背景・音はすべてコードで生成

確認用：`?auto=1&months=12&speed=0.02`（両方 AI で最後まで流す）、`?seed=数字`、`?peek=1`（ノイズの手札を表にする）、`test/`（ルールのテスト）
